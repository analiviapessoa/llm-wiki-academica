# Notas de projeto

Durante os testes com agentes, percebi que o OpenCode funciona melhor para tarefas
diretamente relacionadas a desenvolvimento dentro de um projeto.

O Hermes foi mais útil quando precisei acessar o agente remotamente pelo Telegram
e executar ações persistentes.

No fluxo com GitHub, foi importante especificar claramente o repositório de origem
e o de destino do Pull Request, porque na primeira tentativa o PR foi criado apenas
dentro do fork.

Também houve uma falha temporária do provedor do modelo Nemotron 3.5 Lightning,
mas a mesma operação funcionou posteriormente.
