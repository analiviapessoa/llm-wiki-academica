# Anotação de aula - Agentes

Um agente não é apenas um chatbot. Ele combina um modelo de linguagem
com contexto, ferramentas e um ambiente de execução.

O OpenCode é mais voltado para desenvolvimento e manipulação de código
dentro de projetos.

O Hermes pode funcionar como um agente acessível remotamente, inclusive
por Telegram, e utilizar ferramentas como Git.

Um problema importante é que o agente precisa receber contexto suficiente,
mas contexto demais também pode prejudicar a execução.
