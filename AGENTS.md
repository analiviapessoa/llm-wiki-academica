# AGENTS.md — Regras de Manutenção da LLM Wiki

## Regras para manutenção futura

- `raw/` é **somente leitura**; nunca modificar arquivos nesta pasta.
- Atualizar páginas existentes quando surgir novo conteúdo ou correções necessárias.
- Criar novas páginas quando surgir um assunto novo que se enquadre no escopo da wiki.
- Evitar duplicações — sempre verificar se o tema já foi abordado antes de criar.
- Relacionar páginas usando links Markdown entre páginas relacionadas do `wiki/`.
- Registrar as fontes utilizadas — sempre que possível, incluir referência ao arquivo `raw/atividades/` original.
- Manter `index.md` e `log.md` atualizados após qualquer alteração.
- Ao criar nova página, seguir o padrão de frontmatter YAML opcional e conteúdo em Markdown.
- Usar convenção de nomenclatura `wiki/NN-titulo.md` para páginas novas.
